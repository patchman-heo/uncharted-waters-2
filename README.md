# 대항해시대 II: New Horizons (Uncharted Waters 2) — Godot 4 Port

1993년 코에이(KOEI)의 명작 해양 모험 RPG **대항해시대 2(Uncharted Waters II: New Horizons / 大航海時代II)** DOS 한국어판을 리버스 엔지니어링하여 최신 **Godot 4** 엔진으로 완벽하게 이식한 프로젝트입니다.

---

## 🌟 주요 특징 (Key Features)

* **6인의 주인공 완벽 지원**:
  * 조안 페레로, 카탈리나 에란초, 오토 스피노라, 에르네스트 로페스, 피에트로 콘티, 알 베자스
  * 원작 시나리오 바이트코드(`SNR0..6.DAT`) 및 대사 스크립트(`SNR0..6.MES`) 연동
* **전 세계 130개 항구 & 12종 건물 시스템**:
  * 교역소(시세 및 특산품 교역), 주점(선원 모집, 정보, 도박, 여급), 조선소(선박 건조/개조/수리), 부두(출항/보급), 여관(시간 경과), 왕궁(알현/작위/칙명), 조합(의뢰 퀘스트/아이템 매매), 저택/관저, 은행(예금/대출), 상점(무기/방어구/항해용품/심야 암시장), 교당, 점술관
* **360×216 오픈 월드 해상 항해 시스템**:
  * 풍향/조류(`WINDCUR.DAT`) 물리 연산, 계절별 바람 변화, 식량/식수 소모
  * 해상 괴물(크라켄, 거대 바다뱀 등) 및 폭풍우/악천후 해상 재난
  * 98종의 역사적 유적 및 전설적 발견물 탐색
  * 60여 개 이상의 국가별/해적 AI 함대 실시간 항해
* **전술 함대 해전 & 1:1 선장 일기토(Duel)**:
  * 턴제 함대 결전: 원거리/중거리 포격, 접근 기동, 육박 백병전
  * 선장 간 1:1 진검승부 일기토 시스템 (공격/방어 가위바위보 심리전)
* **칸노 요코(菅野よう子) 작곡 오리지널 사운드트랙 (OST)**:
  * *Wind Ahead*, *Mast in the Mist*, *Caprice for Lute*, *The Chase* 등 전설적인 명곡 13곡 내장
* **편의 시스템**:
  * F5(퀵 세이브), F9(퀵 로드), F11(사운드 음소거)
  * 인물 정보, 함대/적재 화물 목록, 발견물 도감, 시나리오 진행 뷰어, 주요 항구 간 패스트 트래블

## 🚀 실행 방법 (Getting Started)

### 요구 사양
* [Godot Engine 4.3-stable](https://godotengine.org/) 이상

### 실행
```bash
# Godot 4 에디터에서 열기
godot project.godot

# 또는 리눅스 셸에서 직접 실행
./run.sh
```

## 🔍 자가 검증 및 테스트 스위트 (Automated Tests)

프로젝트의 데이터 무결성과 런타임 안정성을 보장하는 자동화 테스트 도구를 제공합니다:

```bash
# 1. 정적 데이터 및 원작 바이너리 그라운드 트루스 검증 (130개 항구 좌표, 이벤트, 타일셋, 음원 무결성)
python3 tools/verify_all.py

# 2. Godot 4 무인 런타임 GUI 자동화 테스트
./Godot_v4.3-stable_linux.x86_64 --rendering-driver opengl3 --script res://tools/autotest.gd
```

## ⚠️ 원작 저작권 고지 (Notice Regarding Original DOS Files)

* 본 저장소에는 **코에이(KOEI)의 원작 DOS 게임 실행 파일 및 상용 바이너리(`DOS/`)가 포함되어 있지 않습니다**.
* 원작 DOS 게임 패키지를 소유하신 경우, 원본 파일들을 `DOS/` 폴더에 넣고 다음 스크립트를 실행하여 데이터 추출 파이프라인을 재실행하실 수 있습니다:
  ```bash
  python3 tools/extract_assets.py
  ```
